# finlo — управленческий учёт для малого бизнеса

Три отчёта из одного журнала операций: **ДДС**, **P&L**, **Баланс**. Заносите приход,
расход и переброски между счетами — отчёты считаются сами и всегда сходятся.

[![CI](https://github.com/PyAlex123/finance_dashboard/actions/workflows/ci.yml/badge.svg)](https://github.com/PyAlex123/finance_dashboard/actions/workflows/ci.yml)

Продукт работает: **[finlo.uz](https://finlo.uz)** — лендинг и вход, кабинет доступен
через Telegram (Web App и вход с компьютера через бота) и Google.

## Что здесь

Полный код продукта: расчётный движок, веб-приложение и тонкий бэкенд.

- **Движок** ([src/engine/](src/engine/), [src/domain/](src/domain/)) — агрегация журнала,
  парсер формул с графом зависимостей и детекцией циклов, периоды, валюты,
  контрольные суммы. Сюда стоит смотреть в первую очередь.
- **Приложение** ([src/features/](src/features/)) — журнал операций на AG Grid, отчёты
  с drill-down, дашборд, редактор шаблона, импорт/экспорт Excel, лендинг и вход.
- **Бэкенд** ([server/](server/)) — FastAPI + SQLite: хранение снимков, авторизация,
  бот Telegram. Без бизнес-логики: весь расчёт на фронтенде, чтобы не разошлись
  две реализации.

Тесты: 45 файлов на фронте (vitest) и 5 на сервере — движок, контрольные суммы и
авторизация покрыты в первую очередь.

## Быстрый старт

```bash
npm ci
npm test          # прогон тестов
npm run dev       # http://localhost:5173 — работает без бэкенда, данные в IndexedDB
```

Серверный режим (общее хранилище, авторизация) поднимается одной командой:
`docker compose --env-file .env.docker up -d --build` — см. [DEPLOY.md](DEPLOY.md).

## Ключевые решения

- **Деньги — целые минорные единицы (тийины) в BigInt.** Никаких чисел с плавающей
  точкой: в учёте копейка, потерянная на округлении, — это несошедшийся отчёт.
- **Одна операция = N проводок.** Приход и расход — одна проводка, переброска между
  счетами — две с суммой ноль. Счета при этом записи справочника, а не колонки таблицы:
  добавление счёта не требует переверстки отчёта.
- **Единственный источник истины — журнал операций.** Отчёты не хранятся, а выводятся;
  ничего вычисляемого в базе нет.
- **Формулы ссылаются на коды статей, а не на адреса ячеек.** Перестановка и
  переименование строк не ломают расчёт; циклы детектируются и показываются понятной
  ошибкой, а не падением.
- **Контрольные суммы считаются постоянно, а не по кнопке.** Расхождение видно сразу
  и с указанием места — молчаливое несхождение недопустимо.

Подробнее — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Структура

```
src/domain/      деньги, коды, типы данных
src/engine/      расчёт отчётов: агрегация, формулы, периоды, проверки
src/features/    экраны: журнал, отчёты, дашборд, шаблон, вход, лендинг
src/data/        хранилища: IndexedDB, API, импорт/экспорт Excel
server/app/      FastAPI: снимки, авторизация, Telegram-бот
deploy/          nginx-конфиги
```
